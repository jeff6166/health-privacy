隐私权政策

应用名称：健康数据周报（个人应用）｜最后更新：2026-09-21｜联系邮箱：jaffe.guo@gmail.com

1. 适用范围

本政策适用于本人在个人电脑上运行的"健康数据周报"个人应用（以下称"本应用"）。本应用仅供账号所有者本人使用，不向公众提供服务，不存在其他用户。

2. 收集哪些数据

经本人明确授权后，本应用通过 Google Health API 读取本人 Google 账号下的以下类别数据：

  • 活动与健身（步数、活动分钟数等）
  • 睡眠（时长、分期、小睡）
  • 健康指标与测量（静息心率、心率变异性 HRV、血氧、呼吸率、睡眠皮温偏差等）
  • 心电图（ECG）记录
  • 饮食记录（本人手动录入的食物条目）
  • 个人资料与位置（仅用于时区与本地日期对齐）

3. 如何使用

仅用于：生成本人的每日/每周健康报告；与既往数据做趋势对比；辅助个人生活方式与训练安排。数据不用于广告、营销、画像或任何形式的自动化决策。

4. 存储与安全

  • 数据保存在本人自有的电脑上（本地文件），不上传至任何第三方服务器。
  • OAuth 令牌保存在本机受限权限文件中，仅本人账户可读。
  • 不将数据纳入任何云端数据库、SaaS 平台或第三方分析服务。

5. 共享与披露

本应用不向任何第三方出售、出租、交换或披露从 Google 获取的数据。以下情形除外：法律法规明确要求时。

6. 保留与删除

  • 本人在本机保留数据的时间由本人决定。
  • 撤销授权：可随时在 Google 账号的"第三方应用与访问权限"页面移除本应用的访问权限（myaccount.google.com/permissions）。
  • 删除数据：删除本机数据文件即完成清除。如需协助，可发送邮件至下方联系邮箱。

7. Google API 服务用户数据的有限使用

本应用对从 Google API 获取的信息的使用遵守 Google API 服务用户数据政策，包括其"有限使用"（Limited Use）要求。

8. 儿童与医疗声明

本应用不面向儿童，不用于医疗诊断或治疗。任何健康决策请咨询专业医疗人员。

9. 政策变更

本政策如有修订，将更新本页面顶部的"最后更新"日期。
